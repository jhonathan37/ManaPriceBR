# ManaPrice BR

Aplicativo Flutter para consulta inteligente de preços de cartas de Magic: The Gathering, cálculo automático de desconto e apoio à venda.

## Objetivo do MVP

- Pesquisar cartas por nome.
- Reconhecer cartas por foto.
- Consultar preços através de uma camada de provedores.
- Aplicar desconto automaticamente.
- Copiar o preço/anúncio para venda.
- Consultar cartas em lote.
- Manter histórico e cache local.

Fundação do aplicativo implementada: configuração Flutter, tema, roteamento inicial e Home.
